## Users
- **Design Leaders & Engineering Directors**: Evaluating high-craft Design Engineers who bridge Figma design systems directly into production-grade React & TypeScript architectures.
- **Founders & Product Teams**: Looking for end-to-end craft, from token foundations and responsive bento layouts to 60fps micro-interactions.
- **Creative Technologists & Peers**: Reviewing code quality, motion fidelity, and editorial layout standards.

## Principles
- **Figma Precision in Production Code**: Design tokens, typography hierarchies, and layout rhythms in code must match or exceed Figma specs.
- **Motion with Gravitas**: Smooth, physics-backed animations (Lenis smooth scroll, Framer Motion transitions) providing spatial continuity and tactile feedback—never gratuitous fluff.
- **Editorial Brutalism**: Dark chromatic aesthetic (`#080808`) paired with high-contrast typography pairings (Syne / Archivo Black display, Space Grotesk body, Instrument Serif italic editorial accents, JetBrains Mono technical readouts).
- **Zero AI Slop**: Avoid generic purple-blue gradients, overused default Inter sans, and repetitive template cards. Every element (volumetric spotlights, noise grain, glass pills, custom magnetic cursor) is deliberately authored.
- **Performance First**: Target 60fps fluid scroll, clean DOM hierarchy, and strict reduced-motion adherence (`useReducedMotion`).

## Key Commitments & Constraints
- **Stack**: React 19, Vite, Tailwind CSS v4 (`@tailwindcss/vite`), Framer Motion, Lenis.
- **Accessibility**: Respect `prefers-reduced-motion`, maintain clear semantic heading hierarchy, ensure AA contrast across active interactive states.
- **Responsive Behavior**: Adaptive from mobile touch displays (custom cursor gracefully hidden via fine-pointer media query) to ultra-wide desktop viewports.
